# 구현 세션 지시문

사용자는 한 세션에 실행 묶음 하나만 지시한다. S04 이후에는 남은 19개 기능 ID를 13개 실행 묶음으로 진행하며, 기존 ID는 범위와 완료 기준 추적용으로 유지한다. 실행 묶음·순서·범위는 [구현 계획](open-markdown.md)이 소유하며, 이 문서는 다음 채팅에 붙여 넣을 실행 지시문이다. 이 PR을 병합한 후 사용한다. 아직 병합 전이면 먼저 사용할 기준 브랜치를 명시하며 에이전트가 PR을 자동 병합하지 않게 한다.
