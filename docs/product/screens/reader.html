앱 구현 전 화면 시안입니다. 본문은 편안하게, 코드와 표는 명료하게 표현하는 기본 방향은 사용자 검토 후 승인되었습니다. 문서 내용·문법 색상·색상·글자 크기·간격은 예시이며 이후 다듬습니다. 미정으로 표시한 세부 동작과 상태 처리는 별도 합의가 필요합니다.

S-01 · 문서 읽기 초안

같은 화면의 최신 디자인 원본 재사용 · 프레임 안에서 스크롤

읽기 화면 · 프레임 안에서 본문 스크롤

문서 읽기 디자인 원본 열기

화면 설명 · 상세 배치는 초안

  1. 1작은 상단 바

    파일명과 뒤로 가기 위치를 제안합니다. 홈에서 직접 연 문서의 상단 뒤로·시스템 뒤로는 홈 복귀로 합의했습니다. 상대 문서 이동 후 복귀와 스크롤 시 상단 바 유지 상세는 미정입니다. 옆 미리보기는 디자인 보드 내 홈으로 이동하며 실제 파일을 열지 않습니다. 단일 행의 뒤로·제목·즐겨찾기·검색·더보기 배치는 디자인 보드와 같은 원본을 사용합니다.

  2. 2편안한 본문

    따뜻한 흰 배경, 넉넉한 줄 간격과 문단 여백. 문서 제목·인용문의 위계를 구분합니다. STUDY NOTES와 제목 등은 앱이 추가한 정보가 아니라 샘플 문서의 내용입니다.

  3. 3구분이 선명한 코드

    본문과 분리된 어두운 블록, 언어 표기와 문법 색상 예시. 문법 강조·복사 버튼·긴 줄의 블록 내부 가로 스크롤은 첫 버전 포함으로 합의했습니다. 긴 줄은 자동 줄바꿈하지 않습니다. 복사 버튼은 정적 시안이며 실제 클립보드를 변경하지 않습니다. 지원 언어와 복사 완료·실패 안내는 미정입니다.

  4. 4표의 구조 유지

    좁은 화면에서는 표 안에서 가로 스크롤하는 안입니다. 표의 가독성과 스크롤 표현은 옆의 원본 디자인 프레임에서 비교합니다.

  5. 5체크리스트 표시

    문서의 완료·미완료 상태를 구분하는 읽기 전용 시안입니다. 터치로 상태를 바꾸는 기능은 포함하지 않았습니다.

  6. 6본문 흐름 속 이미지

    가로 폭에 맞춘 이미지 표시 안입니다. 여기서는 오프라인 SVG 예시를 사용하며 로컬·웹 이미지를 실제로 불러오지 않습니다. 이미지를 탭해 확대 화면을 열고 두 손가락으로 확대·축소하는 기능은 첫 버전 포함으로 합의했습니다. 이 HTML의 이미지는 정적 예시이며 확대의 시각 예시는 디자인 보드에서 제공하며 상세 동작의 미정 사항은 제품 명세를 따릅니다.

즐겨찾기 · 추가 합의

상단 독립 별표로 현재 문서를 즐겨찾기에 추가·해제합니다. 더보기에는 중복 표시하지 않습니다. 기능은 유지하고 위치만 옮깁니다. 이 HTML의 별표 전환은 파일·홈 목록에 저장되지 않으며 새로고침하면 초기화됩니다. JavaScript가 꺼져 있으면 전환 시연은 동작하지 않습니다.

S-02 홈 화면 보기 · 홈과 문서 바로가기 기준

읽기 도구 · 추가 합의

검색 버튼으로 입력 필드가 있는 상단 TopBar를 표시하고, 목차·책갈피는 한 패널의 두 탭으로 제공합니다. 본 시안의 도구 링크는 아래 상태 비교로 이동하며 실제 앱 전환·검색·저장을 수행하지 않습니다. 읽기 도구의 범위와 수용 기준

진입 조건

사용자가 Markdown 파일 하나를 선택한 뒤 문서 읽기를 시작하는 상황입니다. 파일 선택은 시스템 UI를 사용하며 선택 취소 시 홈을 유지합니다. 로컬 이미지는 본문 표시 후 필요한 위치에서 폴더 연결을 안내합니다.

연결 문서

대상 사용자·범위·열린 질문은 제품 방향 문서에서 관리합니다. 이 문서는 요소 동작·진입·화면 상태를 설명하는 명세입니다. 시각 표현은 별도 디자인 문서에서 가져오며 제품 정책을 대신 확정하지 않습니다.

S03은 파일명과 실제 기본 본문(제목·문단·인라인·인용·목록·구분선)을 표시합니다. CommonMark 0.31.2를 기준으로 하며 미지원 코드·이미지·링크·HTML·확장은 실행·이동 없이 원문으로 보존합니다. 미완성 기본 문법은 일반 텍스트 해석을 따릅니다. 후속 단계에서 각 채택 문법을 연결하며 전체 문법 지원 완료를 뜻하지 않습니다. S03 프로필·수용 기준과 S02 로더 정책을 따릅니다. 빈 파일과 읽기 실패·재시도·홈 복귀는 유지하며 디자인 보드의 예시를 실제 내용으로 간주하지 않습니다.

S-01 · 로컬 이미지 접근 안내 / 흐름 합의

로컬 이미지 접근 안내 디자인 원본 열기

본문을 먼저 표시하고, 접근할 수 없는 로컬 이미지 자리에 안내합니다. 연결을 선택하면 폴더 선택을 시작하며 취소해도 본문을 유지합니다. 이 버튼은 정적 시안입니다. 연결한 폴더를 문서 기준으로 하위 상대 경로를 읽고 연결은 재실행 후에도 유지합니다. 웹 이미지는 온라인 읽기·실패 시 본문 유지·재시도를 제공하며, 잘못된 폴더·권한 상실·오프라인 안내·대체 텍스트 상세는 미정입니다.

S-01 · 찾고, 표시하고, 이어 읽기

기능과 검색 진입 방식 합의 · 세부 배치는 검토용

아래는 같은 읽기 화면의 상태 비교입니다. 상단 독립 별표·버튼 앵커 팝업 배치는 앱 적용 대기 검토안입니다. 검색과 저장은 정적 예시이며, 미리보기의 목차·닫기는 각 디자인 프레임 안에서 이동하며 실제 검색·저장을 수행하지 않습니다.

목차·책갈피를 첫 항목으로 두며 모든 기존 도구를 유지합니다. 자동 숨김은 추가하지 않습니다.

① 검색 버튼 → 검색 TopBar

문서 내 검색 디자인 원본 열기

상단 한 줄에 검색 종료·입력 필드·1/3 결과 위치·이전/다음 버튼을 배치합니다. 결과 위치는 전체 중앙이 아니라 입력 필드 옆에 둡니다. 입력과 결과 건수는 디자인 보드의 시연 데이터이며 실제 문서 검색은 수행하지 않습니다. 결과 강조·일치 규칙·닫기 동작과 세부 디자인은 미정입니다.

입력 전·검색 결과 없음도 별도 상태입니다. 입력 전 디자인 · 결과 없음 디자인

② 목차 · 책갈피 패널 / 목차 탭

목차 패널 디자인 원본 열기

제목을 선택하면 해당 위치로 이동합니다. 목차 이동은 디자인 프레임의 시연입니다. 목차·책갈피는 같은 패널의 두 탭이며, 패널 높이·등장 방향·선택 위치 표시는 미정입니다.

제목 없는 문서는 목차 빈 상태로 구분합니다. 목차 빈 상태 디자인

③ 같은 패널 / 책갈피 탭

위치 책갈피 패널 디자인 원본 열기

추가·수정 버튼은 저장하지 않는 정적 시안입니다. 항목 링크는 샘플 위치로만 이동합니다. 이름 수정 입력 화면, 삭제·정렬과 저장 실패 안내는 미정입니다.

책갈피는 가까운 제목과 본문 일부를 자동 표시하며 이름은 원하면 수정합니다. 책갈피 없음 디자인

④ 읽던 위치 기억

같은 문서를 다시 열면 이전 위치에서 이어 읽습니다. 별도의 저장 조작을 요구하지 않는 방향이며 이 HTML은 위치를 저장·복원하지 않습니다. 복원 알림의 필요 여부와 문서 내용이 바뀌었을 때의 처리, 저장 실패 안내는 미정입니다.

공통 정책과 수용 기준: 읽기 편의 기능 명세. 검색어 처리·책갈피 저장 규칙은 여기의 예시 문구로 확정하지 않습니다.
