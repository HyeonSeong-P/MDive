화면 설명 · 상세 배치는 초안

  1. 1작은 상단 바

    파일명과 뒤로 가기 위치를 제안합니다. 홈에서 직접 연 문서의 상단 뒤로·시스템 뒤로는 홈 복귀로 합의했습니다. 상대 문서 이동 후 복귀와 스크롤 시 상단 바 유지 상세는 미정입니다. 이 시안의 뒤로 표시는 동작하지 않는 도형입니다.

  2. 2편안한 본문

    따뜻한 흰 배경, 넉넉한 줄 간격과 문단 여백. 문서 제목·인용문의 위계를 구분합니다. STUDY NOTES와 제목 등은 앱이 추가한 정보가 아니라 샘플 문서의 내용입니다.

  3. 3구분이 선명한 코드

    본문과 분리된 어두운 블록, 언어 표기와 문법 색상 예시. 문법 강조·복사 버튼·긴 줄의 블록 내부 가로 스크롤은 첫 버전 포함으로 합의했습니다. 긴 줄은 자동 줄바꿈하지 않습니다. 복사 버튼은 정적 시안이며 실제 클립보드를 변경하지 않습니다. 지원 언어와 복사 완료·실패 안내는 미정입니다.

  4. 4표의 구조 유지

    좁은 화면에서는 표 안에서 가로 스크롤하는 안입니다. 표의 가독성을 비교하기 위해 실제 HTML 스크롤을 제공합니다.

  5. 5체크리스트 표시

    문서의 완료·미완료 상태를 구분하는 읽기 전용 시안입니다. 터치로 상태를 바꾸는 기능은 포함하지 않았습니다.

  6. 6본문 흐름 속 이미지

    가로 폭에 맞춘 이미지 표시 안입니다. 여기서는 오프라인 SVG 예시를 사용하며 로컬·웹 이미지를 실제로 불러오지 않습니다. 이미지를 탭해 확대 화면을 열고 두 손가락으로 확대·축소하는 기능은 첫 버전 포함으로 합의했습니다. 이 HTML의 이미지는 정적 예시이며 확대 화면 시안과 상세 동작은 아직 작성하지 않았습니다.

즐겨찾기 · 추가 합의

상단 별표로 현재 문서를 즐겨찾기에 추가·해제합니다. 별표 위치는 검토용입니다. 이 HTML에서는 두 스크롤 구간의 별표만 함께 전환되며 파일·홈 목록에 저장되지 않고 새로고침하면 초기화됩니다. JavaScript가 꺼져 있으면 전환 시연은 동작하지 않습니다.

S-01 · 로컬 이미지 접근 안내 / 흐름 합의

▧이미지 폴더를 연결해주세요

본문은 계속 읽을 수 있어요.

본문을 먼저 표시하고, 접근할 수 없는 로컬 이미지 자리에 안내합니다. 연결을 선택하면 폴더 선택을 시작하며 취소해도 본문을 유지합니다. 이 버튼은 정적 시안입니다. 연결한 폴더를 문서 기준으로 하위 상대 경로를 읽고 연결은 재실행 후에도 유지합니다. 웹 이미지는 온라인 읽기·실패 시 본문 유지·재시도를 제공하며, 잘못된 폴더·권한 상실·오프라인 안내·대체 텍스트 상세는 미정입니다.
