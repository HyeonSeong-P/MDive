읽기 화면 · 프레임 안에서 본문 스크롤

문서 읽기 디자인 원본 열기

화면 설명 · 상세 배치는 초안

  1. 1작은 상단 바

    파일명과 뒤로 가기 위치를 제안합니다. 홈에서 직접 연 문서의 상단 뒤로·시스템 뒤로는 홈 복귀로 합의했습니다. 상대 문서 이동 후 복귀와 스크롤 시 상단 바 유지 상세는 미정입니다. 옆 미리보기는 디자인 보드 내 홈으로 이동하며 실제 파일을 열지 않습니다. 단일 행의 뒤로·제목·즐겨찾기·검색·더보기 배치는 디자인 보드와 같은 원본을 사용합니다.

  2. 2편안한 본문

    따뜻한 흰 배경, 넉넉한 줄 간격과 문단 여백. 문서 제목·인용문의 위계를 구분합니다. STUDY NOTES와 제목 등은 앱이 추가한 정보가 아니라 샘플 문서의 내용입니다.

  3. 3구분이 선명한 코드

    본문과 분리된 어두운 블록, 언어 표기와 문법 색상 예시. 문법 강조·복사 버튼·긴 줄의 블록 내부 가로 스크롤은 첫 버전 포함으로 합의했습니다. 긴 줄은 자동 줄바꿈하지 않습니다. 이 HTML의 복사 버튼은 정적 시안이며 실제 클립보드를 변경하지 않습니다. S05 코드 정책은 확정했습니다. 지원 언어의 문법을 강조하고 언어 없음·미지원·강조 실패에는 단색 코드와 복사를 유지합니다. 코드 본문의 공백·탭·빈 줄·끝 개행을 보존해 복사합니다. Android 13 이상은 시스템 성공 안내, 이전 버전은 앱 완료 안내를 사용하며 실패하면 본문과 기존 복사 버튼을 유지합니다. 지원 언어·원문·복사 피드백 기준을 따릅니다. Mermaid는 일반 코드와 구분하여 S07 확정 프로필로 표시합니다.

  4. 4표의 구조 유지

    좁은 화면에서는 표 블록 안에서 가로 스크롤하고 긴 셀은 열 안에서 줄바꿈합니다. 표의 가독성과 스크롤 표현은 옆의 원본 디자인 프레임에서 비교합니다.

  5. 5체크리스트 표시

    문서의 완료·미완료 상태를 구분하는 읽기 전용 표시입니다. 터치로 상태를 바꾸는 기능은 포함하지 않았습니다.

  6. 6본문 흐름 속 이미지

    가로 폭에 맞춘 이미지 표시 안입니다. 여기서는 오프라인 SVG 예시를 사용하며 로컬·웹 이미지를 실제로 불러오지 않습니다. 이미지를 탭해 확대 화면을 열고 두 손가락으로 확대·축소하는 기능은 첫 버전 포함으로 합의했습니다. 이 HTML의 이미지는 정적 예시입니다. S08+S09에서 그림 탭·접근 가능한 확대 동작, 전체 맞춤 초기 상태와 1–8배 핀치·팬을 확정했습니다. 하단에 확대·축소·맞춤 아이콘과 배율, 상단에 닫기를 두며 시스템 뒤로도 기존 본문 위치로 복귀합니다. 다시 열면 맞춤으로 시작합니다. 이미지 지원·캐시·표시·확대 원본 정책을 따르며 디자인 보드는 시각 예시입니다.

즐겨찾기 · 추가 합의

상단 독립 별표로 현재 문서를 즐겨찾기에 추가·해제합니다. 더보기에는 중복 표시하지 않습니다. 기능은 유지하고 위치만 옮깁니다. 이 HTML의 별표 전환은 파일·홈 목록에 저장되지 않으며 새로고침하면 초기화됩니다. JavaScript가 꺼져 있으면 전환 시연은 동작하지 않습니다.

읽기 도구 · 추가 합의

검색 버튼으로 입력 필드가 있는 상단 TopBar를 표시하고, 목차·책갈피는 한 패널의 두 탭으로 제공합니다. 본 시안의 도구 링크는 아래 상태 비교로 이동하며 실제 앱 전환·검색·저장을 수행하지 않습니다. 읽기 도구의 범위와 수용 기준

수식 · S06 동작 확정

GitHub 작성 안내의 인라인 달러·달러/백틱, 새 줄의 이중 달러 블록과 math fence를 인식하는 제한 TeX 프로필입니다. 코드와 원문 보존 중인 링크·HTML은 제외하고 빈 내용·미완성 입력은 원문으로 유지합니다. 정상 수식에는 TeX 원문을 접근성 설명으로 제공하며 긴 인라인 식은 별도 행의 수식 영역 안에서 가로로 읽습니다. 정상 수식의 별도 원문 보기·확대는 제공하지 않습니다.

미지원 명령이나 렌더 실패는 해당 위치에 ‘수식을 표시하지 못했어요’와 ‘원문 보기’를 제공합니다. 버튼으로 구분자 또는 fence를 포함한 읽기 전용 원문 시트를 열고, 별도 닫기 버튼 없이 아래로 스와이프·바깥 영역 탭·시스템 뒤로로 시트만 닫아 기존 본문 위치로 돌아옵니다. 주변 본문은 계속 읽을 수 있습니다. 수식 허용 명령·환경·처리 한계·실패·수용 기준을 따르며 디자인 보드의 미정 표기는 이 확정 정책을 대신하지 않습니다.

Mermaid · S07 동작 확정

mermaid fence의 flowchart/graph·sequenceDiagram·classDiagram·stateDiagram-v2·erDiagram 다섯 종류를 Mermaid 11.15.0 오프라인 번들로 표시합니다. 외부 요청·링크 실행·HTML·문서 지정 설정은 허용하지 않습니다. 준비 중에는 해당 그림 영역에 스켈레톤을 표시하고 주변 본문은 유지합니다. 로딩 배너는 두지 않습니다. 문서 세션에서 완료된 렌더 결과를 재사용해 스크롤 복귀와 확대 시 엔진을 다시 실행하지 않습니다.

정상 다이어그램도 원문 보기를 제공합니다. 지원 밖 입력·렌더 실패·한계 초과에는 ‘다이어그램을 표시하지 못했어요’와 ‘원문 보기’를 제공합니다. fence를 포함한 읽기 전용 원문 시트는 별도 닫기 버튼 없이 아래로 스와이프·바깥 영역 탭·시스템 뒤로로 닫고 본문 위치를 유지합니다.

정상 다이어그램의 탭으로 전체 맞춤 확대 화면에 진입합니다. 맞춤 대비 1–8배 핀치 확대·축소, 팬과 맞춤 복원을 제공합니다. 확대·축소·맞춤 아이콘과 배율 표시는 하단의 한 컨트롤 영역에 묶고 닫기는 상단에 둡니다. 닫기·시스템 뒤로는 기존 본문 위치로 복귀합니다. 재진입은 전체 맞춤으로 시작합니다. 지원·실행·처리 한계·확대·수용 기준이 원본이며 아래 디자인 보드의 미정 문구·시연은 이 확정 정책을 대신하지 않습니다. 이미지 확대의 상세 정책은 별도입니다.

진입 조건

사용자가 Markdown 파일 하나를 선택한 뒤 문서 읽기를 시작하는 상황입니다. 파일 선택은 시스템 UI를 사용하며 선택 취소 시 홈을 유지합니다. 로컬 이미지는 본문 표시 후 필요한 위치에서 폴더 연결을 안내합니다.

연결 문서

대상 사용자·범위·열린 질문은 제품 방향 문서에서 관리합니다. 이 문서는 요소 동작·진입·화면 상태를 설명하는 명세입니다. 시각 표현은 별도 디자인 문서에서 가져오며 제품 정책을 대신 확정하지 않습니다.

S03은 파일명과 실제 기본 본문(제목·문단·인라인·인용·목록·구분선)을 표시합니다. CommonMark 0.31.2를 기준으로 하며 미지원 코드·이미지·링크·HTML·확장은 실행·이동 없이 원문으로 보존합니다. 미완성 기본 문법은 일반 텍스트 해석을 따릅니다. 후속 단계에서 각 채택 문법을 연결하며 전체 문법 지원 완료를 뜻하지 않습니다. S03 프로필·수용 기준과 S02 로더 정책을 따릅니다. 빈 파일과 읽기 실패·재시도·홈 복귀는 유지하며 디자인 보드의 예시를 실제 내용으로 간주하지 않습니다.

S04는 GFM 표·읽기 전용 task·이중 물결표 취소선을 연결합니다. 표만 가로로 읽고 task는 탭·포커스·편집 동작을 제공하지 않습니다. 정확한 인식 규칙과 GFM 예외는 S04 프로필·수용 기준을 따릅니다. 아래 디자인 예시가 후속 미구현 콘텐츠의 동작을 뜻하지는 않습니다.

본문을 먼저 표시하고, 접근할 수 없는 로컬 이미지 자리에 안내합니다. 연결을 선택하면 폴더 선택을 시작하며 취소해도 본문을 유지합니다. 이 버튼은 정적 시안입니다. 연결한 폴더를 문서 기준으로 하위 상대 경로를 읽고 연결은 재실행 후에도 유지합니다. S08+S09에서 잘못된 폴더·권한 거부/상실·파일 없음은 이유와 이미지 폴더 연결을 제공하도록 확정했습니다. 취소는 기존 연결을 유지합니다. HTTPS 웹 이미지의 오프라인·요청 실패에는 alt(없으면 이미지)와 실패 이유·다시 시도를 표시합니다. 로컬 연결과 웹 재시도를 구분하며 최초 준비 중에는 그림 영역 스켈레톤을 표시합니다. 경로·권한·요청 한계·캐시·수용 기준이 원본이며 이 HTML은 실제 파일이나 네트워크 요청을 수행하지 않습니다.
