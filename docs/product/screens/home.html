즐겨찾기와 최근 문서를 한곳에서 만나는 홈 화면입니다.

홈 시안의 기본 구성은 사용자 검토 후 승인되었습니다. 세부 디자인과 미정 정책은 이후 구체화합니다. 파일 열기·즐겨찾기·최근 문서를 첫 버전에 포함합니다. 아래 파일명·날짜·개수·별표는 예시입니다. 옆 미리보기는 독립 디자인 문서의 최신 보드를 그대로 불러옵니다. 미리보기의 이동·피드백은 시연이며 실제 파일·저장을 수행하지 않습니다. 요소 동작·상태·합의 여부는 이 명세와 연결된 제품 문서가 소유합니다.

화면 설명 · 상세 표현은 초안

  1. 1새 문서 열기

    홈에서 Markdown 파일 선택을 시작합니다. 선택이 끝나면 읽기 화면 S-01로 이동하며 선택 취소 시 홈을 유지합니다. 이 HTML 버튼은 비활성화한 정적 표현이며 실제 파일을 선택하지 않습니다.

  2. 2즐겨찾기는 가까이에

    사용자가 지정한 문서 바로가기를 최근 문서보다 위에 둡니다. 별표는 지정 상태의 예시이며 홈의 별표 자체는 버튼이 아닙니다. 추가·해제는 읽기 화면의 별표에서 합니다.

  3. 3최근 문서로 다시 읽기

    최근에 읽은 순서로 문서를 표시합니다. 각 항목을 선택하면 해당 문서를 엽니다. 미리보기의 샘플 항목은 디자인 프레임 안의 읽기 보드로 연결되며, 별도 읽기 화면 명세는 아래 연결 문서에서 확인합니다.

  4. 4첫 실행은 단순하게

    아직 연 문서가 없으면 목록 대신 파일 열기를 중심으로 안내합니다. 정상적인 빈 상태이며 오류 안내가 아닙니다.

상단바와 화면 여백 · 확정

홈 상단은 기존 브랜드 아이콘만 표시하며 앱명 글자를 반복하지 않습니다. 본문 기본 여백은 사방 16dp입니다. 컴포넌트 내부와 시스템 영역은 별도 기준을 따릅니다.

진입과 화면 이동

앱 시작 시 홈 S-02에서 출발하는 안입니다. 파일 선택 또는 문서 바로가기 → 읽기 화면 S-01. 홈에서 직접 연 문서의 상단 뒤로·시스템 뒤로는 홈 복귀입니다. 돌아왔을 때의 목록 갱신과 스크롤 유지 방식은 상세 검토가 필요합니다.

열린 결정

즐겨찾기 정렬, 최근 문서 표시·보관 개수, 두 목록의 중복 표시 정책, 항목 제거 시 관련 정보 보관 범위, 접근 권한 복구 흐름은 미정입니다. 시안의 개수와 배치는 제한이나 확정 정책이 아닙니다.

문서에 접근할 수 없을 때 · 초안

기존 문서 접근 실패 디자인 원본 열기

문서 선택 후 실패한 상태의 예시입니다. 항목을 자동 삭제하지 않고 실패 이유와 파일 다시 연결·목록에서 제거를 제공합니다. 목록 제거는 원본을 삭제하지 않습니다. 홈 목록을 유지한 채 복구 다이얼로그에서 파일 다시 연결·목록 제거·닫기를 제공합니다. 목록 제거는 별도 확인을 거칩니다. 권한 복구·재연결과 관련 정보 보관의 상세 정책은 미정입니다.
