# MDive 제품 방향

상태: 기획 전 메모. 아래의 미정 항목은 요구사항이 아니다.

## 현재 합의

- Android용 Markdown 뷰어 앱을 만든다.
- 구현은 Kotlin, Jetpack Compose, MVI, Hilt를 사용한다. 여러 화면의 이동에는 Navigation 3를 사용한다.
- 사용자 시나리오와 기능 요구사항은 아직 정의하지 않았다. 이 문서는 기획 과정에서 수정한다.

## 기획 시 결정할 질문

1. 누구의 어떤 Markdown 문서를 보는 앱인가? 핵심 사용자와 첫 사용 시나리오는 무엇인가?
2. 문서는 파일 선택기, 공유 인텐트, URL, 앱 내부 목록 중 어디에서 가져오는가? 여러 진입점이 필요한가?
3. 읽기 전용 범위는 어디까지인가? 검색, 목차, 최근 문서, 즐겨찾기, 편집, 내보내기는 필요한가?
4. CommonMark와 GitHub Flavored Markdown 중 어떤 문법을 지원할 것인가? 표, 체크박스, 수식, 코드 강조는 필요한가?
5. 상대 경로 이미지·링크와 외부 링크는 어떻게 처리할 것인가? 오프라인 동작과 실패 상태는 무엇인가?
6. 큰 문서, 다크 모드, 글자 크기, 접근성, 태블릿 화면에서 기대하는 경험은 무엇인가?
