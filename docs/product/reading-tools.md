# 읽기 도구

합의 상태: 목차·검색·읽던 위치 기억·문서별 위치 책갈피 제공 합의. 세부 화면 배치는 초안.

## 사용자와 목표

긴 공부 문서에서 필요한 내용을 찾고, 다시 볼 위치를 저장하며, 다음에 이어 읽는다.

## 핵심 시나리오와 범위

- 목차의 제목을 선택해 해당 부분으로 이동한다.
- 검색 버튼을 누르면 상단에 입력 필드가 있는 검색 TopBar를 표시하고 현재 문서 안의 단어를 찾는다.
- 상단 검색바 한 줄에 종료 진입점·검색 입력 필드·현재 결과 위치/전체 건수·이전/다음 버튼을 함께 배치한다. 결과 위치는 `1/3` 형식으로 입력 필드 옆에 표시한다. 두 줄 구성과 전체 중앙 정렬은 사용하지 않는다.
- 문서를 다시 열면 저장된 읽기 위치에서 이어 읽는다.
- 책갈피는 기기 내에 저장해 앱 재실행 후에도 유지한다.
- 한 문서에 여러 위치 책갈피를 저장하고, 목록에서 선택하면 해당 위치로 이동한다. 문서 즐겨찾기와 별개의 기능이다.
- 문서 수정으로 책갈피 위치를 찾을 수 없으면 임의의 위치로 이동하지 않는다. 저장해둔 제목·본문 미리보기와 함께 위치를 찾을 수 없음을 안내한다.
- 책갈피는 가까운 제목과 본문 일부를 자동으로 표시해 구분하며 이름은 원하면 수정한다. 매번 이름을 입력해야 저장되는 흐름으로 만들지 않는다.
- 목차와 책갈피 목록은 한 패널의 두 탭으로 제공한다. 페이지 번호 기반 책갈피나 페이지 넘기기를 추가하는 합의는 아니다.

## 수용 기준

- 목차 항목을 선택하면 해당 제목 위치로 이동한다.
- 검색 버튼으로 상단 입력 필드에 접근하고 현재 문서의 검색어 일치 위치를 찾을 수 있다.
- 검색 결과가 있으면 상단 입력 필드 옆에서 현재 결과 위치·전체 건수를 확인하고 이전/다음 결과로 이동할 수 있다.
- 같은 문서를 다시 열면 저장된 읽기 위치로 복귀한다.
- 책갈피는 앱을 다시 실행한 후에도 유지한다.
- 현재 읽는 위치를 책갈피로 추가하고 한 문서에서 여러 책갈피를 구분해 선택할 수 있다.
- 책갈피를 추가할 때 이름 입력 없이 자동 표시 정보를 제공하고, 사용자가 원하면 이름을 수정할 수 있다.
- 목차와 책갈피 탭을 전환해 각각의 목록에 접근할 수 있다.
- 책갈피 위치를 복원할 수 없으면 임의 이동 없이 저장된 제목·본문 미리보기와 위치를 찾을 수 없음 안내를 제공한다.

## 열린 결정

- 검색 TopBar 닫기와 시스템 뒤로 동작, 입력 포커스·키보드 표시 시점.
- 검색 대상(코드·표 포함 여부 등), 일치 규칙, 결과 강조, 처음·마지막 결과의 이동 규칙과 결과 없음 안내.
- 제목 없는 문서의 목차와 책갈피 자동 표시, 같은 위치 중복 추가, 이름 편집·삭제의 상세 흐름.
- 위치 기억 시점과 저장 범위, 앱 재실행 후 읽던 위치 정보의 유지 범위, 문서 변경 시 읽던 위치 복원 및 저장 실패 처리. 책갈피 위치 판별 방식과 복원 불가 후 재지정·삭제 흐름.
- 패널 형태·높이, 책갈피 추가 버튼 위치와 완료 피드백.

시안의 예시 이름·문구·검색 건수나 버튼 배치는 열린 결정을 확정하지 않는다.
