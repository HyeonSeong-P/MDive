# MDive 디자인 산출물

기존 제품 기획과 와이어프레임을 유지하며 별도로 검토하는 디자인 초안이다. 제품 동작의 원본은 [제품 방향](../product/overview.md)과 연결된 기능 명세다.

- [제품 화면 디자인 열기](screens/index.html): 홈·읽기·도구·확대·오류 등 34개 화면/상태와 Compose 이식 설명.
- [화면 디자인 검토·검증 안내](screens/README.md): 실행 방법, 공통 토큰 대응, 검증 범위.
- [Markdown 콘텐츠 디자인 시스템 확장 목록](markdown-components.md): 문법별 필요한 표현, 기존 자산과 차이, 신규 API 제안, 다음 세션 구현 순서와 검증 예제 계획.

후속 작업은 Markdown 콘텐츠 컴포넌트의 HTML·Compose 카탈로그 확장부터 진행한다. 이 문서 묶음에는 제품 기능이나 새 디자인 시스템 컴포넌트 구현이 포함되지 않는다.
