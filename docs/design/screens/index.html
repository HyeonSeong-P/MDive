읽는 데 집중하는 화면.

디자인 시스템으로 조합한 제품 화면 · 시각 초안

이 파일은 구현용 디자인 초안입니다. 동작 원본은 제품 명세·화면 설계서이며, 이 문서는 최신 DS를 적용한 시각 디자인입니다. 합의된 기능에 디자인을 제안하며, 배치·문구·미정 동작을 확정하지 않습니다. 샘플 문서·목록·건수는 모두 예시입니다.

HTML의 CSS만으로 Compose 이식 명세가 완성되지는 않습니다. 화면 옆의 Compose 대응·토큰·상태 계약을 함께 참고하세요. 공통 컴포넌트의 사용 기준과 화면 전용 영역을 구분합니다. 공통 값은 실행 카탈로그와 토큰 원본을 따릅니다. 검토 도구의 테마 선택은 제품 설정이 아닙니다.

공통 구현 기준과 미정 사항
  • CSS 1px ≈ 기준 Android 1dp, 글꼴 px ≈ 기본 fontScale 1의 sp를 표현한 검토 좌표입니다. 실제 픽셀 일치 보장은 아닙니다. 390 × 844는 프레임 예시이며 실제 기기 치수가 아닙니다.
  • 시스템 바 높이를 앱에 고정하지 마세요. 호스트에서 실제 WindowInsets를 적용합니다. 화면에는 상태바/탐색바의 검토용 영역만 표시합니다. 모달·IME 인셋은 중복 적용하지 않습니다.
  • 화면은 State / Intent / Effect / BaseViewModel을 사용합니다. UI는 이벤트만 전달하고 파일 선택·외부 링크·클립보드 같은 일회성 동작은 호스트 Effect로 처리합니다. 미정된 저장 정책이나 파서 선택은 이 디자인이 정하지 않습니다.
  • 최소 터치 touch, 선택 의미·전체 파일명 낭독·입력 레이블 제공. 내용은 색상만으로 구분하지 않습니다. 큰 글자에서 텍스트를 자르지 않고 높이를 확장합니다. 검색 한 줄의 큰 글자·극소 폭 대응과 태블릿은 구현 전 추가 합의가 필요합니다.
  • 본문 최대 폭·태블릿 분할·가로 모드·큰 문서 최적화는 미정입니다. 여기서는 휴대폰 세로 시각 초안을 제공합니다. 본문은 데이터·slot 기반 Markdown DS API로 조합합니다. 문법 해석·파일 로딩·렌더 엔진은 포함하지 않습니다.
  • 모달 닫기/복귀/검색 IME/책갈피 저장·복원 정책 등 아래 미정 사항은 구현 전에 합의합니다. HTML의 이동은 디자인 검토용이며 앱 내비게이션 정책이 아닙니다.
